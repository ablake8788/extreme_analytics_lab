3. RUN WITH THE LOGIN ON THIS PC (SERVER MODE)
==============================================================================
  a. Close the .exe if it is running (it holds port 5100):
       Stop-Process -Name ExtremeAnalyticsLab -ErrorAction SilentlyContinue

  b. Edit the private settings file:
       notepad config.local.ini
     Set:
       [app]
       mode = server

       [server]
       password = your-password
     Save and close.

  c. Start from source:
       .\.venv\Scripts\Activate.ps1
       python run.py

  d. Open http://127.0.0.1:5100 and press Ctrl+F5 -> Sign in page.
     After signing in, "Log out" is at the top right.

  e. Check what the app sees (optional):
       python -c "from app.server_settings import load_settings; s=load_settings(); print('mode:', s.mode, '| password set:', bool(s.password))"

  f. When done: Ctrl+C, then set  mode = local  again in config.local.ini.

  No login showing?
    - You are running the .exe -> use python run.py instead
    - Select-String -Path app\__init__.py -Pattern "init_security"
      must print 2 lines; if not:  python apply_web_deployment.py
    - config.local.ini: mode = server must be under [app]
    - Old page cached -> Ctrl+F5

==============================================================================
7. SETTINGS FILES
==============================================================================
  config.ini          shared defaults, in git, packed into the .exe.
                      [app] mode = local. NEVER put a password here.
  config.local.ini    PRIVATE, this PC only, never committed or uploaded.
                      mode, password, secret key for local login testing.
  Environment vars    web host only (APP_MODE, APP_PASSWORD, APP_SECRET_KEY,
                      APP_DOMAIN). They override both ini files.
  Order (later wins): config.ini > config.local.ini > environment variables.

9. TROUBLESHOOTING
==============================================================================
  Script "is not recognized"      -> not in the project folder:  dir *.ps1
  Scripts blocked                 -> Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
                                     Get-ChildItem *.ps1 | Unblock-File
  Port 5100 busy / old app shows  -> Stop-Process -Name ExtremeAnalyticsLab
  .venv locked / pip broken       -> close VS Code and app windows, pause Dropbox,
                                     then .\rebuild.ps1
  config.py error on line 1       -> Get-Content app\config.py -TotalCount 1
                                     must print: import configparser
  Browser shows old page          -> Ctrl+F5
  Anything else                   -> copy the last 30-40 lines of red text
                                     and ask for help
