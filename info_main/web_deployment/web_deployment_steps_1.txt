==============================================================================
KEY FACTS
==============================================================================
- You deploy the SOURCE CODE to GoDaddy (app\, run.py, passenger_wsgi.py,
  requirements.txt, config.ini) - not the .exe. Web hosting runs Linux.
- One code base, three ways to run it:

    How it starts                     Login?        Used for
    --------------------------------  ------------  ---------------------------
    .\launch.ps1  (the .exe)          never         everyday use on your PC
    python run.py  (mode = local)     no            development on your PC
    python run.py  (mode = server)    yes           testing the web login
    GoDaddy  (passenger_wsgi.py)      always        the real website

- Login = ONE shared password. There is no user name.
- Settings are read in this order; later wins:
    1. config.ini          shared, in git, packed into the .exe (NO secrets)
    2. config.local.ini    private, this PC only, never committed
    3. environment variables   GoDaddy (cPanel > Setup Python App)
- Where the domain name is kept:
    1. Registration: GoDaddy > My Products > Domains (or the company's registrar)
    2. DNS: a record pointing the name to the GoDaddy hosting
    3. The app: environment variable APP_DOMAIN (never in the code)
- Safety: in server mode the app refuses to start without a password and a
  secret key, so it is never online unprotected. build.ps1 refuses to build
  the .exe if config.ini says mode = server.


==============================================================================
PART A - GODADDY ACCOUNT SETUP (about 30 minutes)
==============================================================================
1. GET THE RIGHT HOSTING PLAN
   godaddy.com > My Products.
   - Have Web Hosting: Manage > cPanel Admin > Software > "Setup Python App".
   - No hosting: buy Web Hosting (cPanel, Linux). Ask GoDaddy chat first:
     "Does this plan include Setup Python App for Python 3.9 or newer?"
   - Do NOT use Windows/Plesk hosting.
   - "Setup Python App" missing: ask GoDaddy support to enable Python.

2. CHOOSE THE ADDRESS
   Option 1 - subdomain of an existing company domain (recommended):
     cPanel > Domains > Create a New Domain (or Subdomains)
     e.g. analytics.yourcompany.com
     DNS managed outside GoDaddy: add an A record for "analytics" pointing
     to the hosting IP (shown in cPanel's right-hand panel).
   Option 2 - new domain: GoDaddy > Domains > buy, then cPanel > Domains.

3. TURN ON HTTPS
   cPanel > Security > SSL/TLS Status > select the domain > Run AutoSSL
   (can take up to an hour).

4. TURN ON SSH (optional, recommended)
   My Products > Web Hosting > Manage > Settings > SSH access > on.

==============================================================================
PART C - PUT THE APP ON GODADDY
==============================================================================
11. UPLOAD THE CODE
    cPanel > Files > File Manager > home folder (NOT public_html)
    > create folder: extreme_analytics_lab
    > upload extreme_server.zip > right-click > Extract.

12. CREATE THE PYTHON APP
    cPanel > Software > Setup Python App > Create Application
      Python version .............. newest offered (3.9 or higher)
      Application root ............ extreme_analytics_lab
      Application URL ............. your domain or subdomain
      Application startup file .... passenger_wsgi.py
      Application entry point ..... application
    Click Create.

13. ADD ENVIRONMENT VARIABLES (same screen)
      APP_MODE ........ server
      APP_DOMAIN ...... analytics.yourcompany.com
      APP_PASSWORD .... a strong password (the shared sign-in password)
      APP_SECRET_KEY .. a long random string (at least 16 characters)
    For AI reports:
      OPENAI_API_KEY .. your OpenAI key (never in config.ini)
    Optional:
      APP_UPLOAD_MAX_AGE_HOURS .. 24   (uploads deleted after this)
      APP_SESSION_HOURS ......... 12   (how long a sign-in lasts)
    Click Save. These never go into git.
    Make a random secret key on your PC:
      python -c "import secrets; print(secrets.token_hex(32))"

14. INSTALL THE PACKAGES
    "Configuration files": add requirements.txt > Run Pip Install
    (pandas and numpy take several minutes).
    If it fails, use SSH: run the "source activate" command shown at the top
    of the app screen, then:
      pip install -r requirements.txt

15. START IT
    Click Restart at the top of the app screen.

FILES THAT MAKE UP THE WEB DEPLOYMENT
==============================================================================
  passenger_wsgi.py          GoDaddy start file (always server mode)
  app\server_settings.py     reads config.ini > config.local.ini > env vars
  app\security.py            sign-in page, lockout after 5 wrong tries,
                             secure cookies, Log out button, upload clean-up
  config.local.ini.example   template for your private settings
  config.local.ini           PRIVATE - never committed or uploaded
  apply_web_deployment.py    one-time patch (step 5)
  make_server_zip.ps1        builds extreme_server.zip (step 10)
  test_all.ps1               runs every test (step 6)
  tools\live_check.py        live checks used by test_all.ps1
  tests\test_server_mode.py  unit tests for local/server mode
  info_main\reference\       reference document for AI reports (in the server zip)
  On the web the report is returned to the browser (Save As dialog); the
  server never writes to a reports folder.
