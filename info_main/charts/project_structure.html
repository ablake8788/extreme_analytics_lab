Extreme & Change Analytics Lab

Project structure. Run every command from the extreme_analytics_lab folder.

script run in PowerShell or Python app application code test automated tests generated created automatically, not in git
extreme_analytics_lab\
Project root
apply_time_filter.py script
One-time patch that adds the From / To time filter to api.py and app.js
run.py app
Starts the web app at http://127.0.0.1:5100
config.ini app
Default parameters (K_E, window, ROC and others), host and port
requirements.txt
Python packages: Flask, pandas, numpy, openpyxl, pytest
build.ps1 script
Checks the venv, installs packages, runs tests, builds the .exe
rebuild.ps1 script
Creates a fresh .venv, installs, runs tests, starts the app from source
launch.ps1 script
Starts the built .exe and opens the browser
.gitignore
Keeps .venv, uploads, build and dist out of git
app\
The application package
__init__.py app
create_app(): builds the Flask app and finds its files inside the .exe
config.py app
Reads config.ini into the Config class
routes\
URLs the browser calls
web.py app
Serves the main page ( / )
api.py app
/api/upload, /columns, /analyze, /report, /time_range
services\
The logic, with no web code
extreme_change_engine.py app
Extreme, Change, Persistence and Materiality calculations
data_loader.py app
Reads CSV/XLSX, handles the sensor layout, builds DateTime, applies the time filter
report_generator.py app
Builds the analysis report
models\
Placeholder package
templates\
HTML pages
index.html app
Page layout: upload, columns, time period, parameters, results
static\
Files sent straight to the browser
css\app.css app
Light theme styling
js\app.js app
Upload, form, chart, results table, From / To filter
tests\
Run by build.ps1 and rebuild.ps1 before anything else
test_extreme_change_engine.py test
Engine matches the framework's worked example
test_data_loader.py test
Both file layouts, daylight-saving order, time filter
test_report_generator.py test
Report output
info_main\charts\
Project documentation, including this chart
uploads\ generated
Files uploaded in the app
.venv\ generated
Python environment, excluded from Dropbox sync
build\ generated
PyInstaller temporary files
dist\ExtremeAnalyticsLab.exe generated
The finished executable

How a request flows

index.html + app.jsYou upload a file and click Run
→
routes\api.pyReceives the request
→
data_loader.pyReads and filters the data
→
extreme_change_engine.pyRuns the analysis
→
app.jsDraws the chart and table
